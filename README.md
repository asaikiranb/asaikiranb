## Projects

**Multimodal RAG · HVAC Field Assistant** (Contextual AI Capstone)  
Retrieval system for field technicians over WhatsApp. Voice input via Faster-Whisper, image/diagram parsing with YOLO + PaddleOCR, BAAI/bge-m3 embeddings indexed in Qdrant, orchestrated with LangGraph. Built to maintain retrieval quality across modalities without blowing up latency on a WhatsApp roundtrip.

**LLM Guardrail Auditor**  
Evaluation framework that stress-tests pipelines against documented failure vectors: hallucination, retrieval misalignment, refusal drift, prompt injection. Outputs per-category scores with flagged examples.

**VentureScope · Text-to-SQL Agent**  
Natural language to SQL over startup market data. Includes a query decomposition step before generation, schema routing for multi-table queries, and a self-correction loop on execution errors. FastAPI backend, deployed.

**Portfolio RAG Assistant** · [saikiranb.com](https://saikiranb.com)  
Ask-me-anything interface over my own work history and writing. Local embeddings, semantic chunking, Groq for inference, Next.js frontend.
